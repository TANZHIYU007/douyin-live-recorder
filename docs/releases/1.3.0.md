# 拾光 Lumina v1.3.0

从录制工具扩展到完整的本地录像整理与回看流程。Full 与 Lite 功能相同，只是依赖携带方式不同。

## 新功能

- **本地录像库**：按场次整理视频、弹幕和分片，扫描全局及主播独立保存目录；支持搜索主播/标题、打开目录和外部播放。
- **弹幕搜索与同步回放**：跨场搜索弹幕内容或用户名，双击结果定位画面；内置播放器支持暂停、拖动、分片连续播放、静音和临时延迟补偿。
- **主播独立录制方案**：在「选中主播 → 更多 → 此主播的录制方案」中设置画质、目录、格式、分片、录制内容、事件类型和字幕参数，也可恢复跟随全局。
- **持久化录后处理队列**：录完自动排队封装字幕，逐个处理；失败原因保留、可手动重试，重启继续处理未完成任务。

## 可靠性改进

- 新录像保存 `.session.json`，记录分片起点、时长及录制参数；回放和补做字幕复用时间轴，识别起录与断线空档。
- 字幕处理及成品校验失败不再误报成功；保留失败片段原文件，重试时跳过已处理分片。
- 处理完成后自动更新录像库的文件、大小和状态，播放前检查文件是否被后台替换。
- 修复标题含英文句点时文件名截断、重连片段可能覆盖前一片段的问题。
- 对损坏弹幕记录、异常配置、超大场次及不可读视频时长增加容错与明确提示。
- 发布构建加入真实媒体回归、打包后播放与跳转检查；Full 验证内置浏览器与媒体工具，离线构建检查不依赖抖音连通性。

## 下载选择

- **Lumina-Full.exe**：自带 Chromium、FFmpeg、FFprobe，推荐一般用户使用。
- **Lumina-Lite.exe**：复用系统 Edge（其次 Chrome）及 FFmpeg/FFprobe；内置回放组件，但录制和封装仍需要媒体工具。
- **SHA256SUMS.txt**：两个程序的 SHA-256 校验值。文件大小以本页附件为准。

## 升级与使用提醒

1. 停止录制、退出旧版，再替换程序。保留录制目录，并建议备份 `%LOCALAPPDATA%\Lumina` 中的配置、队列和登录状态。
2. 旧视频与 JSONL 可直接进入录像库。缺少时间记录的旧场次会推算时间轴，起录及断线附近可能有偏差，可在回放中调整延迟。
3. 请随视频一起保留 `.jsonl` 和 `.session.json`。只录了视频，无法恢复未保存的弹幕；同步回放读取 JSONL，不解析 XML。
4. 主播方案默认跟随全局；启用独立方案并保存后，停止该房间再重新开始生效，不打断当前录制。
5. 跨场搜索最多显示 500 条结果；单场回放最多载入 20 万条事件，从搜索结果进入大场次时载入命中附近的记录。

本版不包含定时录制计划。实际直播录制仍受平台接口、网络和风控影响；离线自检通过不代表已经验证真实直播间。
Windows 程序暂无代码签名；macOS 打包脚本仍未进行真机验证。
